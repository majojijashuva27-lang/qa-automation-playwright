# QA Automation Project

## Overview

This project demonstrates web application quality assurance and test automation using Playwright and TypeScript.

## Testing Areas

- Functional Testing
- UI Automation Testing
- Smoke Testing
- Regression Testing
- Negative Testing
- Cross-Browser Testing

## Tools & Technologies

- Playwright
- TypeScript
- Node.js
- Git
- GitHub Actions

## Project Objective

The objective of this project is to create a maintainable test automation framework and validate important web application functionalities using automated test cases.
